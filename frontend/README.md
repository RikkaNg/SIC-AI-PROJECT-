
  # Web page for data display

  
  ## Running the code
  tạo file tên frontend xong cho tải full cái này cho vào file đấy
  
  tải thêm file data csv : https://drive.google.com/file/d/1MuzcQxwr8LzIZ-60FS8zYH_A79NZHgii/view?usp=sharing
  
  tải file data xong thì tạo file tên public bên trong frontend xong để data vào đấy
  
  nó nên như này
  
  frontend
    -public
      -data
    -...
    -...
  
  mở powershell rồi chạy code dưới ở file đang lưu:
  
  python -m uvicorn src.api:app --reload --port 8000
  
  Run `npm i` to install the dependencies.
  
  tạo cửa sổ powershell mới chạy ở file frontend rồi chạy code dưới
  
  Run `npm run dev` to start the development server.
